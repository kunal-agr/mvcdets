**MVC DETS** is a full-featured expense tracking system designed to help users monitor their daily spending habits with precision and ease. Built using enterprise-standard Java web development practices, this application demonstrates clean MVC architecture, secure authentication, and comprehensive CRUD operations.

<div align="center">

```
┌──────────────────────────────────────────────────────────────┐
│                        🌐 CLIENT LAYER                        │
│                     (Web Browser / Mobile)                    │
└────────────────────────────┬─────────────────────────────────┘

                             ▼
┌──────────────────────────────────────────────────────────────┐
│                     🎮 CONTROLLER LAYER                       │
│              (UserServlet / ExpenseServlet)                   │
│  • Route incoming requests                                    │
│  • Validate input data                                        │
│  • Coordinate business logic                                  │
│  • Prepare response data                                      │
└────────────────────────────┬─────────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────────┐
│                      💼 SERVICE LAYER                         │
│                      (Business Logic)                         │
│  • Authentication & Authorization                             │
│  • Data validation & transformation                           │
│  • Business rules enforcement                                 │
└────────────────────────────┬─────────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────────┐
│                       🗄️ DAO LAYER                           │
│         (UserDAOImpl / ExpenseDAOImpl + JDBC)                 │
│  • Database connection management                             │
│  • CRUD operations                                            │

                             │
                             ▼

│                       📦 MODEL LAYER                          │
│                   (User / Expense POJOs)                      │
│  • Data representation                                        │
│  • Entity definitions                                         │
│  • Getters & Setters                                          │
└────────────────────────────┬─────────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────────┐
│                      🖼️ VIEW LAYER                           │
│                (JSP Pages + Bootstrap CSS)                    │
│  • User interface rendering                                   │
```

### ⚙️ Prerequisites

Before you begin, ensure you have the following installed:

| Software | Version | Download Link |
|----------|---------|---------------|
| ☕ **JDK** | 17+ | [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) |
| 🗄️ **PostgreSQL** | 14+ | [PostgreSQL Downloads](https://www.postgresql.org/download/) |
| 🚀 **Apache Tomcat** | 11.0+ | [Tomcat Downloads](https://tomcat.apache.org/download-11.cgi) |
| 📦 **Maven** | 3.6+ | [Maven Downloads](https://maven.apache.org/download.cgi) |
| 🔧 **Git** | Latest | [Git Downloads](https://git-scm.com/downloads) |
| 💻 **IDE** | Any | IntelliJ IDEA / Eclipse / NetBeans |

### 📥 Installation Steps

#### **Step 1: Clone the Repository**
```bash
git clone https://github.com/kunal-agr/mvcdets.git
cd mvcdets
```

#### **Step 2: Set Up PostgreSQL Database**

Open PostgreSQL command line or pgAdmin and execute:

```sql
-- Create database
CREATE DATABASE mvcdetsdb;

-- Connect to database
\c mvcdetsdb

-- Create users table
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL
);

-- Create expenses table
CREATE TABLE expenses (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(100) NOT NULL,
    amount NUMERIC(10,2) NOT NULL,
    category VARCHAR(50),
    expense_date DATE NOT NULL
);

-- Create indexes for better performance
CREATE INDEX idx_expenses_user_id ON expenses(user_id);
CREATE INDEX idx_expenses_date ON expenses(expense_date);
CREATE INDEX idx_users_email ON users(email);
```

#### **Step 3: Configure Database Connection**

Navigate to `src/main/java/com/kagrawal/utils/DBConnection.java` and update:

```java
private static final String URL  = "jdbc:postgresql://localhost:5432/mvcdetsdb";
private static final String USER = "your_postgres_username";
private static final String PASS = "your_postgres_password";
```

#### **Step 4: Build the Project**
```bash
mvn clean install
```

#### **Step 5: Deploy to Tomcat**

**Option A: Using IDE**
1. Import the project as a Maven project
2. Configure Apache Tomcat 11 in your IDE
3. Add the project to Tomcat
4. Start the server

**Option B: Manual Deployment**
1. Copy the generated `.war` file from `target/` directory
2. Paste it into Tomcat's `webapps/` folder
3. Start Tomcat server

#### **Step 6: Access the Application**

Open your browser and navigate to:
```
http://localhost:8080/MVC_DETS/index.jsp
```

### 🎉 First Time Setup

1. 📝 Click **Register** to create a new account
2. 🔐 **Log in** with your credentials
3. 💸 Start adding expenses from the **dashboard**!

## 🗄️ Database Schema

The application uses an efficient **two-table relational design** with proper normalization and referential integrity:

### 👥 Users Table
**Purpose:** Stores user account information and credentials

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| 🔑 `id` | SERIAL | PRIMARY KEY | Unique user identifier |
| 👤 `name` | VARCHAR(50) | NOT NULL | User's full name |
| 📧 `email` | VARCHAR(100) | UNIQUE, NOT NULL | Login email (unique) |
| 🔒 `password` | VARCHAR(255) | NOT NULL | Hashed password |

**Indexes:**
- `PRIMARY KEY` on `id`
- `UNIQUE INDEX` on `email`

### 💸 Expenses Table
**Purpose:** Stores individual expense records linked to users

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| 🔑 `id` | SERIAL | PRIMARY KEY | Unique expense identifier |
| 👤 `user_id` | INT | FOREIGN KEY → users(id) | Owner of the expense |
| 📝 `title` | VARCHAR(100) | NOT NULL | Expense description |
| 💰 `amount` | NUMERIC(10,2) | NOT NULL | Expense amount (decimal) |
| 🏷️ `category` | VARCHAR(50) | NULL | Expense category |
| 📅 `expense_date` | DATE | NOT NULL | Date of expense |

**Indexes:**
- `PRIMARY KEY` on `id`
- `FOREIGN KEY INDEX` on `user_id`
- `INDEX` on `expense_date` for faster date queries

### 🔗 Relationships & Constraints

```sql
users (1) ─────< (M) expenses
  └─ ON DELETE CASCADE
     (Deleting a user removes all their expenses)
```

**Key Features:**
- ✅ **One-to-Many Relationship**: One user can have multiple expenses
- 🗑️ **Cascade Delete**: Removing a user automatically deletes their expenses
- 🔒 **Data Isolation**: Foreign key constraint ensures data integrity
- 🚀 **Optimized Queries**: Proper indexing for fast data retrieval

Contributions are what make the open-source community an amazing place to learn, inspire, and create. Any contributions you make are **greatly appreciated**! 🎉

### 🌟 How to Contribute

1. **🍴 Fork the Project**
   ```bash
   # Click the 'Fork' button at the top right of this page
   ```

2. **📥 Clone your Fork**
   ```bash
   git clone https://github.com/your-username/mvcdets.git
   cd mvcdets
   ```

3. **🌿 Create a Feature Branch**
   ```bash
   git checkout -b feature/AmazingFeature
   ```

4. **✍️ Make your Changes**
   - Write clean, documented code
   - Follow existing code style
   - Add comments where necessary

5. **✅ Commit your Changes**
   ```bash
   git add .
   git commit -m 'Add: AmazingFeature - Description of changes'
   ```

6. **📤 Push to your Branch**
   ```bash
   git push origin feature/AmazingFeature
   ```

7. **🎉 Open a Pull Request**
   - Go to the original repository
   - Click 'New Pull Request'
   - Describe your changes clearly

### 📋 Contribution Guidelines

| Category | Guidelines |
|----------|-----------|
| 💻 **Code Style** | Follow Java naming conventions, use meaningful variable names |
| 📝 **Documentation** | Update README for new features, add JavaDoc comments |
| ✅ **Testing** | Test thoroughly before submitting, include test cases if possible |
| 🐛 **Bug Reports** | Use issue templates, provide reproduction steps |
| ✨ **Features** | Discuss major changes in issues first, keep PRs focused |
